Copy AI ID Manual Test Page

Hovering should highlight targets only. Click a highlighted target or press Space after hover/Arrow-key navigation to open the target-attached notebook for that element. Press Shift + Control + Space to toggle Copy AI ID on or off only for this page scope.

  • Normal click while ON: page-native click should be blocked and the notebook should open for the clicked target.
  • Bare Space: confirm the current highlighted target and open the notebook without copying yet.
  • Notebook: Enter inserts a line break; Shift + Enter or Save copies the note, clears the draft, and hides the notebook.
  • After saving, reopen another target from the page and continue editing the cumulative notebook text directly.
  • Press Shift + Control + Space: only this page scope should turn OFF until Shift + Control + Space is pressed again.

Keyboard DOM navigation

Hover a child in this fixture, then use the Arrow keys to move through layout-tree DOM nodes, including wrappers without data-ai-id. After keyboard navigation, press Space to insert a reference when the highlighted node has data-ai-id, or to show the missing-id toast otherwise.

  • Hover any child, move with Arrow keys, then press Space to add a reference for the currently highlighted data-ai-id node.
  • Focus the notebook collapse and Save controls, then press Space to confirm their native overlay actions still win.
  • Focus the host editable fields above while Copy AI ID is ON, then press Space or Shift + Control + Space to confirm Copy AI ID shortcuts win; use the notebook textarea for normal note typing.
  • In the notebook, use Enter for a line break and Shift + Enter or Save to copy/clear/hide.
  • After selecting multiple targets, confirm the notebook text can be edited directly without relying on saved target icons.
